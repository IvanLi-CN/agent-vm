# Agent VM Web 管理台

## Scope and visitor mode

- Primary target：随 Agent VM 产品交付的 `web/` 应用；当前尚无实现。
- Mode：Operate。
- 受众与任务：维护者检查已有 Agent 会话 VM，判断镜像与容量状态，执行受控维护，并追踪操作结果。
- 产品事实以 [PRODUCT.md](../../PRODUCT.md) 为准；全局视觉约束以 [DESIGN.md](../../DESIGN.md) 为准；API、权限和状态边界以 [管理台合同](../../docs/specs/agent-vm/contracts/management-api.md) 及 [OpenAPI](../../docs/specs/agent-vm/contracts/management-api.yaml) 为准。
- 当前任务仅更新文档合同；管理台本身仍未实现。已批准的实施计划覆盖后续代码与验收工作。

## First surface and navigation

首个认证后的页面为 Overview，提供容量、准入、压力、排空和来源新鲜度。导航顺序为 Overview、VMs、Images、Operations & Audit、System。首个交互验证面为 VM 清单与详情：页面标题、筛选与更新时间在清单上方，选中 VM 后在旁侧显示身份、租约、状态依据、影响和允许的动作。

标志性交互是“检查与操作并列”：点选或用键盘选择一行，详情与动作一起更新，目标身份始终可见。切换目标不能沿用上一目标的确认；有未提交输入时明确处理，不能静默丢失或提交给另一个目标。危险动作在其上下文中出现，不作为常驻的全局主按钮。清单没有手动创建 VM 的入口。

宽屏采用并列布局；空间不足时在清单与详情间切换，保留筛选、选择和返回位置。窄屏确认仍能看到目标与影响。首版视觉验收检查 1440、1024 和 390 CSS px；这些视口不扩展设备覆盖承诺。

## Task flows and proof

- VM：定位会话与实例，核对镜像身份、资源、租约和状态时间，再选维护动作。影响有效租约时显示受影响会话、原因输入和明确确认；提交后关联持久操作 ID。后端重新校验权限、状态与 generation，冲突时解释变化并要求重新核对。
- 镜像：区分可信源导入与本地上传，进入同一完整性、适用性和引用管理流程。版本展示不可变身份；默认标记与会话固定镜像分开。导入、校验和删除显示阶段、结果和可恢复的操作入口；删除被引用资源时列出阻碍，不能提供绕过规则的按钮。
- 概览与系统：容量、准入、压力、排空、组件状态与来源新鲜度分开呈现。未知值有解释及定位入口，不汇总为一个绿色总分。
- 操作与审计：按目标和操作身份查询阶段、结果、执行者、原因与时间，浏览器刷新后可继续追踪。超时或断开先恢复查询，不把请求错误显示为已执行失败，也不自动重提。

页面使用后端白名单 DTO 与有界错误，不展示原始命令、凭据、部署路径或未授权清单。示例数据必须标注为合成数据，不能充当现网状态或性能证明。

影响现有 VM 或镜像、切换默认镜像及系统维护动作通过匹配的 API 预览后提交；确认 token 绑定操作者、目标、参数和资源版本。镜像导入作为有大小、校验和与 staging 余量约束的持久长操作直接开始。操作请求携带 UUID、原因和目标版本，VM 请求同时提交 generation。请求冲突时重新加载并预览，不自动把动作应用到更新后的目标。

## State and content coverage

实现时至少准备以下内容情形作为组件与流程验证输入；它们是合成样例，不是现网规模测量或容量承诺。

- 清单为空、仅一条、多页；筛选无结果与系统无资源使用不同解释。
- 长会话名、长 fingerprint、缺失的可选值、多单位数值；关键标识可完整查看与复制。
- 首次加载、后台刷新、部分来源失败、过期、未知或尚未验证；每项保留对应来源和更新时间。
- VM 活跃租约、已停止缓存、操作进行中、并发变更与状态冲突；不把缓存表达为持久存储承诺。
- 镜像上传或导入中、完整性失败、适用性失败、staging 磁盘不足、默认镜像与不同引用阻止删除。
- 无管理员权限、登录过期、管理入口不可用和请求超时；保留可安全恢复的导航与查询上下文，不自动重放维护操作。
- 简体中文和英文的完整布局、长文案、辅助名称和结构化错误；语言优先级为已保存选择、浏览器偏好、英文回退。

异步操作的阶段变化使用有限、可理解的反馈；刷新不打断当前阅读。表格与确认流程需要覆盖键盘、明确焦点、错误关联和非颜色状态表达，并检查文本缩放与减少动态效果。具体可访问性验收标准在实现任务中落定，不宣称已有认证。

## Direction contract

**THESIS:** Overview 先呈现容量、准入、压力与来源新鲜度；进入资源检查后，在同一任务上下文核对对象、影响与动作，不用大块统计卡片挤占工作空间。

**OWN-WORLD:** 浅灰框架包围白色工作面，导航和选中行保持中性；深青蓝用于数据与焦点，石墨黑用于主要提交动作。共享列、紧凑无衬线文字与标识等宽字体支持比较，危险与未知有独立文字表达。具体数值见 DESIGN.md 的首版实施基线。

**STORY:** 维护者先定位会话，再理解状态与影响，明确提交并持续查询结果。选中后固定上下文的交互贯穿 VM、镜像引用与操作记录；动效只解释选择、展开与状态变化。

**FIRST VIEWPORT:** 默认打开 Overview；左侧为窄导航，主体按可比较的信息组呈现容量余量、准入与排空、运行压力和数据来源新鲜度，并显示观测时间。首屏不以装饰性统计卡片或单一“健康”结论替代依据。

**VM CHECK VIEWPORT:** 页面标题、筛选和更新时间位于清单上方；主体为 VM 清单，右侧显示选中对象的身份、状态依据与影响，动作紧随其后。未选择时给出检查提示；窄屏按清单到详情展开，确认保持目标可见。

**FORM:** 用户选择的“检修工作台：清单与受控操作并列”；本轮自有候选第 5 项，direction seed `f11fe76d`，assigned。此选择确定首版实现基线，不替代实现后的视觉验证。具体视觉基线进一步采用 design-taste-frontend 的 `framed-sheet`，seed `1399279798`，未重抽；推导与适配见 [视觉研究笔记](../../.taste-skill/brief.md)。

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

上述 FINISH 约束后续实际构建；本次初始化没有可验收 UI，也不宣称已完成该构建检查。Direction contract 只供开发与评审使用，不进入浏览器资源、页面内容或客户端包。

## Open inputs and review boundary

浅色方向、色板、字体和初始尺寸已在 DESIGN.md 形成首版实施基线。深色主题不在当前交付范围；实际字体加载和组件交互状态仍需在界面中验证，当前没有已实现设计系统 sidecar。界面代码完成后运行 `$impeccable document`，提取实际系统并核对方向。

界面语言已固定为 `zh-CN` 与 `en`，默认认证后落点为 Overview。真实代理 UID、外部 Origin、管理员主体、可用镜像来源、上传上限、staging 余量与隔离资源是部署启用输入，缺少必要配置时管理入口关闭。键盘、缩放、减少动态效果与错误关联需要在实际界面中提供证据；本文不宣称这些实现检查已经完成。
