# 管理台产品需求

本页是 Agent VM 内置 Web 管理台的主题 PRD，回答维护者为什么需要它、完成哪些任务以及明确不做什么。协议字段、错误结构和兼容窗口仍以[管理 API 合同](../agent-vm/contracts/management-api.md)及其 OpenAPI 文件为准；项目级定位见根目录 [PRODUCT.md](../../../PRODUCT.md)。

## 用户和问题

主要用户是负责 Agent VM 运行环境的维护者。客户端用户通过既有 CLI 管理自己的会话，部署人员负责受保护的发布和恢复，开发者维护客户端、Go 服务、合同和文档。管理台解决维护者需要在一个入口观察容量、定位会话、管理可信镜像并跟踪有副作用的操作，而不是把低层 Incus 资源直接暴露给浏览器。

## 关键任务

1. 查看容量、准入、运行压力、排空状态、任务清单和数据新鲜度，判断当前是否可以承接新需求。
2. 找到一个已有 session，理解 task、generation、租约、原生状态、来宾可用性和最近错误，再执行授权的维护动作。
3. 导入并验证镜像来源，区分完整性和 Agent VM 适用性，管理不可变 fingerprint、默认选择和安全退役。
4. 通过预览、原因、二次确认、operation 阶段和审计记录跟踪每个维护动作，保留未知结果而不是猜测终态。
5. 查看服务、版本、能力、认证主体和来源健康，知道何时应转交部署运维流程。

## 首版页面

| 页面 | 产品结果 |
| --- | --- |
| 概览 | 把容量、准入、压力、任务和新鲜度分开表达，避免“绿色健康”掩盖未知数据。 |
| VM | 以 session 为入口查看资源、租约、generation、来宾连接和可执行的受控动作。 |
| 镜像 | 以 fingerprint 和引用关系管理新会话基础镜像，默认切换不影响旧会话。 |
| 操作与审计 | 通过 operation ID、阶段、结果、原因和人工接管信息追踪长任务与不确定结果。 |
| 系统 | 展示服务身份、版本、能力、认证和数据来源，不泄露凭据、原始命令或部署路径。 |

## 产品行为

- 管理台使用同源 `/api/v1`，由 Go 服务作为 OIDC relying party 建立浏览器会话；后端每次重新检查权限、当前状态和资源身份。
- 重启、扩容、释放租约、停止、销毁和镜像删除先提供影响预览，要求维护者填写原因并二次确认；浏览器断开或请求超时不会自动取消、重做或宣告失败。
- 默认镜像只影响新会话；已有 VM 和缓存保留原 fingerprint。删除镜像前必须处理默认、活跃 VM、缓存和进行中的创建引用。
- 缺失、未验证、失败、过期或 `null` 的值必须保留状态语义，不能显示成零、成功或正常。

## 边界

管理台不提供管理员手动创建 VM、任意 Incus 实例接管、宿主机/PVE 管理、通用网络或存储管理、独立 start/stop/pause、快照/克隆/迁移、Web terminal、镜像自动构建或自动部署控制。Caddy 只负责 TLS、固定路径转发和静态资源，不执行 Forward Auth、身份头注入或资源授权。

## 成功标准

维护者能够从概览判断数据是否新鲜，定位目标 session 并理解动作影响，查询 operation 到明确终态或保留未知结果，管理镜像引用而不误改旧会话，并在必要时通过系统页面和部署文档转入受保护运维流程。页面行为、响应结构和审计事实都能回到本主题合同或项目级 PRD。
