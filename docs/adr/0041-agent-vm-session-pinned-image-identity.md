# Agent VM 会话固定不可变镜像身份

管理台需要导入、校验和管理多个基础镜像，并允许维护者切换默认镜像。默认镜像只决定新会话的初始环境；已有会话的 VM 与缓存继续绑定其不可变镜像身份，直到该会话明确销毁并重新创建环境。修改 alias 或默认镜像不得隐式重建、替换或使全部旧缓存失效。

这个选择保留会话工作环境的连续性，代价是控制服务必须持续管理旧镜像引用、兼容性与回收条件。镜像删除必须检查现存 VM、缓存、进行中的创建操作以及默认镜像引用；默认切换与新建会话的镜像选择必须有明确的事务顺序。

现行实现仍将缓存记录的 fingerprint 与全局配置 fingerprint 比较，并在不匹配时返回 `cache_stale`。本决定是已确认的目标行为，尚未实施；落地时必须同步修改 [CLI 合同](../specs/agent-vm/contracts/cli.md)、[Agent VM Spec](../specs/agent-vm/SPEC.md)、生命周期与状态兼容规则，不能仅修改页面。镜像身份核验或适用性检查失败时仍须拒绝恢复；切换默认镜像本身不再构成旧缓存失效理由。
