# 管理台使用指南

内置管理台面向经过授权的维护者，管理已有 Agent 会话 VM、受管镜像、容量状态和有审计的维护动作。它不是 VM 自助申请平台，也不包装 CLI 输出；稳定行为以[管理 API 合同](../specs/agent-vm/contracts/management-api.md)、[项目 PRD](../../PRODUCT.md)和[管理台主题 PRD](../specs/management-console/PRD.md)为准。

## 五个页面

| 页面 | 用途 | 关注点 |
| --- | --- | --- |
| 概览 | 判断当前是否可以承接新需求 | 容量、准入、压力、排空、任务状态和数据新鲜度 |
| VM | 定位已有会话工作环境 | session、task、generation、租约、原生状态和来宾可用性 |
| 镜像 | 管理新会话可用的基础镜像 | 来源、fingerprint、适用性、默认选择和引用 |
| 操作与审计 | 追踪维护动作 | 预览、确认、operation、阶段、结果和原因 |
| 系统 | 查看服务和认证边界 | 版本、能力、认证主体、数据来源和故障提示 |

首个认证后的页面是概览。页面可以显示静态入口或深链接，但管理 API 始终要求有效的浏览器会话和后端授权。

## 典型操作

先在概览确认数据来源和新鲜度，再进入 VM 页面选择目标会话。重启、扩容、释放租约、停止或销毁等动作先展示受影响的 session、资源、租约和可能的数据影响，维护者填写原因并二次确认；后端会在提交前重新检查权限、generation 和当前状态。

镜像操作分别检查完整性和 Agent VM 适用性。切换默认镜像只影响新会话；已有 VM 和缓存保持原 fingerprint。删除前必须处理默认引用、活跃 VM、停止缓存和正在创建的引用，不能用可变 alias 代替不可变内容身份。

## 结果和审计

浏览器断开、请求超时或页面刷新不会自动取消、重做或判定原生动作失败。回到操作与审计页面，以 operation ID、session、generation 和阶段查询同一动作；结果未知时应保持待确认，不把 HTTP 成功或单个健康指标当作业务终态。

容量、运行压力、准入和健康是不同判断。缺失、未验证、失败、过期或 `null` 必须保留原语义；页面不会显示未经授权的凭据、原始命令诊断或部署路径。

## 认证和边界

管理台由 Go 服务作为 OIDC relying party 建立浏览器会话，通过同源 `/api/v1` 提供结构化管理接口。Caddy 只负责 TLS、固定路径转发和静态资源，不执行 Forward Auth、身份头注入或资源授权；具体 issuer、管理员 `(issuer, subject)` allowlist、Origin、TLS 和资源限制属于部署输入。

管理台不提供宿主机/PVE 管理、任意 Incus 实例接管、Web terminal、镜像自动构建或自动部署控制。出现部署或状态后端故障时，转到[部署运维指南](../../deploy/docs/maintenance.md)和[故障排查](troubleshooting.md)，不要在浏览器中直接修改服务或数据库。
