# Agent VM 文档站范围说明

文档站的目的是展示项目使用与设计文档。读者应直接进入文档，通过导航、目录、正文链接和图表理解内容。方便人类检查设计是阅读质量目标，不意味着建设独立审阅工作台。

首期先完成设计，再建设最小独立 Fumadocs 站点。首页以 Agent VM 使用指南和开发文档为入口；本主题完整材料收在开发文档的文档站主题下。正文保持单源，增强表达按具体内容选择图表、方案对比和交互示例。

独立需求追溯页、异常关联演示及额外的设计关联声明已经退出范围。未来若建设审阅功能，应围绕文档、版本、段落与反馈另行明确需求。

管理台上下文帮助、全量项目文档和生产／Demo 接入依次后置。当前合同见 [SPEC](../specs/documentation-review/SPEC.md)，实际能力见 [实现覆盖](../specs/documentation-review/IMPLEMENTATION.md)。
